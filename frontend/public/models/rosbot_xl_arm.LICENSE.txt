rosbot_xl_arm.glb
==================

This .glb is a static, non-articulated assembly of the ROSbot XL base (all arm joint angles
held at 0, the URDF's own rest/zero pose) built from meshes and URDF/xacro offsets drawn from
two upstream packages, from two different copyright holders, both under Apache License 2.0:

1) BASE (chassis + 4 non-mecanum wheels)

  Source:     https://github.com/husarion/rosbot_ros
  Path:       rosbot_description/meshes/rosbot_xl/{body.dae, wheel_a.dae, wheel_b.dae}
              rosbot_description/urdf/rosbot_xl/{body.urdf.xacro, wheel.urdf.xacro,
              rosbot_xl_macro.urdf.xacro}  (offsets only, no mesh geometry)
  Commit:     41fad02196ee200a39e01579c75391385cc9b714 (branch: main)
  License:    Apache License, Version 2.0 (reproduced in full below)
  Copyright:  Husarion sp. z o.o.
  Retrieved:  2026-08-31

  Note: the base mesh/URDF used to live in a standalone `husarion/rosbot_xl_description`
  repository, referenced by name from husarion/rosbot_xl_manipulation_ros's xacro
  (rosbot_xl_manipulation_description/urdf/rosbot_xl_manipulation.urdf.xacro). That
  standalone repository no longer exists on GitHub (404) - its content was folded into the
  husarion/rosbot_ros monorepo (rosbot_description package now covers both ROSbot and
  ROSbot XL). Apache-2.0 license text and Husarion copyright are unchanged by that move; see
  "notes" in rosbot_xl_arm.json for more on husarion/rosbot_xl_manipulation_ros's archival.

2) ARM (OpenMANIPULATOR-X: 5 links + 2 gripper fingers, mounted per
   rosbot_xl_manipulation_ros's cover_link offset, joint angles at 0)

  Source:     https://github.com/ROBOTIS-GIT/open_manipulator (branch: humble)
  Path:       open_manipulator_x_description/meshes/{link1..5,gripper_left_palm,
              gripper_right_palm}.stl
              open_manipulator_x_description/urdf/open_manipulator_x.urdf.xacro
              (offsets only, no mesh geometry)
  Commit:     84b68b219a0fa30b223ad7e3c268d1f11fa43577 (branch: humble)
  License:    Apache License, Version 2.0 (reproduced in full below)
  Copyright:  ROBOTIS CO., LTD.
  Retrieved:  2026-08-31

  Note: the `humble` branch is used deliberately, not `main` - `main` renamed this package
  to `open_manipulator_description` and restructured it for a newer OpenMANIPULATOR
  product line; `humble` is the branch whose package is still named
  `open_manipulator_x_description`, matching what husarion/rosbot_xl_manipulation_ros's
  xacro (and, by inheritance, husarion/rosbot_ros) depends on for OpenMANIPULATOR-X.

3) MOUNTING / PART OFFSETS (arrangement only - no mesh geometry, no separate copyright claim
   beyond what's already covered above)

  Source:     https://github.com/husarion/rosbot_xl_manipulation_ros
  Path:       rosbot_xl_manipulation_description/urdf/rosbot_xl_manipulation.urdf.xacro
  Commit:     82b18a8b889c7b067d9896a5c5afb3b36177a014 (branch: main/HEAD)
  License:    Apache License, Version 2.0
  Copyright:  Husarion sp. z o.o.
  Retrieved:  2026-08-31

  Note: this repository was archived by Husarion on 2025-08-05; development moved to
  husarion/rosbot_ros. The archived repository remains accessible on GitHub and its final
  state is what was used here. This does not affect the mesh content or its Apache-2.0
  license - it only affects where future updates to this integration would need to look.

Both upstream packages declare "Apache 2.0" / "Apache License 2.0" in their package.xml
<license> tag, and both source repositories' root LICENSE files contain the identical
Apache License 2.0 boilerplate (byte-for-byte diffed to confirm). There is no license
mismatch between the base and the arm.

This .glb is a derivative work: the base's 5 COLLADA (.dae) meshes and the arm's 7 STL
meshes were assembled per the joint/visual offsets in the xacro files above (all arm joint
angles held at 0 - the URDF's zero pose, requiring no rotation math beyond one per-wheel
180-degree spin already present in wheel.urdf.xacro), decimated, and re-exported as a single
static scene. See frontend/scripts/build-rosbot-xl-arm-glb.mjs for the exact process, which
is the modification this License's Section 4(b) requires be noted.
