husky_a200.glb
==============

NOTE ON REVISION: this repository (husky/husky) describes the Husky A200 (classic), NOT
the newer, larger Husky A300. husky.urdf.xacro's base footprint properties (base_x_size
0.9874m, base_y_size 0.5709m, track 0.555m, wheel_length 0.1143m) combine to a ~990 x
~669mm footprint, matching Clearpath's published A200 dimensions (990 x 670 x 390 mm)
almost exactly - and this repo has no A300 xacro/mesh variant at all (A300 is described in
Clearpath's separate, newer clearpath_common ROS 2 repository). husky_a200.glb's own final
bounding box (990 x 396 x 669 mm) confirms this: it matches the A200 spec to ~0.5-1.6%, and
would be off by ~4% on width against the A300's 698mm.

This .glb is a static, non-articulated conversion of those meshes: base_link, top_chassis,
the default top_plate, the front and rear bumpers, and all four wheels were assembled per
the offsets and origins in husky_description/urdf/husky.urdf.xacro (default configuration:
HUSKY_FRONT_BUMPER=1, HUSKY_REAR_BUMPER=1, HUSKY_TOP_PLATE_ENABLED=true, no large top plate,
no PACS), decimated, and re-exported. The user_rail and all PACS/sensor-mount accessories
are NOT included (fine mounting/bracket hardware, not needed for silhouette recognition).
See frontend/scripts/build-husky-glb.mjs and the "Regenerating the robot model" section of
frontend/README.md for the exact process, which is the modification the license below asks
be reflected in redistributed copies.
